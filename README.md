# Naija Quiz 🇳🇬

A simple quiz application that tests your knowledge of Nigeria.

## Features
- Choose from different quiz categories.
- Answer 10 random questions per round.
- Get instant feedback on your answers.
- View your final score.
- Copy and share your result.

## Built With
- React
- TypeScript
- CSS
